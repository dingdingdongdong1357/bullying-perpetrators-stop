# 讓國中霸凌加害者停手的是什麼

2026「資料科學漫步」參賽作品〈別再只教受害者自保：讓國中霸凌加害者停手的是什麼〉的分析程式。報告全文見 [`report/`](report/)。

## 研究問題與主要發現

使用 TIGPS 2023（國一）、2024（國二）兩波追蹤資料，串連學生、家長與導師問卷：

1. **受害者怎麼做，結果都沒有明顯差異**。2,111 位受害者中，告訴老師、告訴家人、忽略、回擊……一年後脫離受害的比例都在 53% 上下。
2. **加害受害者最難停手**。1,182 位加害者一年後約六成停手；同時也被欺負的加害者只有 56% 停手，35% 一年後仍在霸凌、也仍被欺負。
3. **風險會疊加**。家裡會打、常被批評、同時被欺負、網路成癮、好友會惹事，5 項中有 0–1 項的加害者約八成停手，4 項以上只剩 44%（每多一項，勝算比 0.66）。
4. **以為有用、但未偵測到差別**（信賴區間偏寬，不等於沒有效果）：父母離婚、家境，以及導師的各種處理方式（通知父母、請輔導老師協助、處罰等）。

```bash

```

## 方法摘要

| 項目 | 做法 |
|---|---|
| 結果變數 | 脫離受害 / 停手：2023 年是受害者（加害者），2024 年回答沒有 |
| 模型 | 邏輯斯迴歸，報告勝算比（OR = e^β） |
| 控制變項 | 受害者：性別、受害嚴重度、是否也加害；加害者：性別、加害嚴重度、是否同時受害、班級加害率 |
| 標準誤 | TIGPS 以班級為單位抽樣，依班級群聚校正 |
| 累積風險 | 5 項 2023 年風險（0/1）加總；檢驗階梯、每多一項的 OR，並以 AIC 與分開放入的模型比較 |

## 資料使用聲明
